# MeshFlow M9 beta update

This update removes the experimental unread-message keyboard blink and its setting. It retains the keyboard wake safeguard and immediate keyboard-light shutoff on manual screen sleep. It also includes the recent message and node-list layout, theme readability, settings navigation, and Power Statistics updates.

- Target: `thinknode_m9-tft` (Elecrow ThinkNode M9).
- Application size: 4,028,896 bytes.
- SHA-256: `50c2777462873605d7a84ab89f774b8c27f0534ae8f947d84af34dd45bd32ad6`.
- Flash image: `release/firmware.bin`; checksum: `release/SHA256SUMS`.
- The firmware build passed; the changes require hardware testing. Installation and recovery guidance: see `INSTALLATION.md`. The Meshtastic Web Flasher upload workflow has not yet been tested on an M9.
- Source and build details: see `SOURCE-NOTES.md`.
