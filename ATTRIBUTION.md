# Source and attribution

MeshFlow includes source derived from the [Meshtastic firmware](https://github.com/meshtastic/firmware) and [Meshtastic Device UI](https://github.com/meshtastic/device-ui). The source snapshots retain their respective copyright notices and license files: [firmware license](firmware/LICENSE) and [Device UI license](device-ui/LICENSE). Both included files contain the GNU General Public License, version 3. Other components and assets may carry additional notices in their own directories.

The `firmware/protobufs/` and `firmware/meshtestic/` directories are exported upstream sources at the revisions recorded in [SOURCE-NOTES.md](SOURCE-NOTES.md); retain their included licenses and notices. The Device UI includes third-party materials whose attribution and redistribution terms must also be respected. Bundled map tile archives are excluded from this repository pending review of their redistribution terms; see `device-ui/maps/README.md` for map sources and attribution.

MeshFlow's interface is inspired by WADAMESH. The development project's source notes state that WADAMESH was used as a visual reference; it is not included in this source package.
